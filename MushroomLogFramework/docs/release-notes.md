# Release Notes

## 2.0.0

Released 28 October 2025 for SMAPI 4.3.2 or later.

- Revamped the data asset for much more flexibility. This is NOT a backwards-compatible change. 1.0.0 is deprecated.
- Adds support for fruit trees influencing mushroom log outputs.
- Adds more control over what the output of a mushroom log will be.
- Added MIT license.
